# heroine_voice_v1

Model: Kokoro-82M v1.1-zh, ONNX int8 export from thewh1teagle/kokoro-onnx model-files-v1.1.
Runtime: kokoro-onnx 0.6.1. Chinese frontend: misaki 0.9.4, ZHG2P(version="1.1").
Voice: zf_001. Speed: 0.95. Output: 24kHz mono, game OGG.

Direction: calm, clear adult female delivery, restrained emotion. This is an artistic direction, not a claim that the model has an emotion-conditioning control. Voice remains the same across all key lines.

Only exact approved-integration text from voice_manifest.json is synthesized. Do not clone a real person or imitate an actor. Do not add words, omit clauses or read line IDs aloud.

Model, voice bank and phonemizer remain authoring dependencies and never enter the Windows release.
