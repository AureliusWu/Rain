## 已实现

原生历史记录绑定 560 个稳定台词 ID，只有真实已读记录可以新增收藏；旧存档没有 ID 时仅接受唯一的原说话人/原文匹配。收藏独立于剧情存档，支持章节筛选、删除和原录音重听。查看、筛选和重听不修改路线、随机数、章节或历史条数。原生历史另外支持章节筛选，清除同时恢复关键词、人物和章节。

收藏以条目时间保存新增/删除事件，使用 Ren'Py 的 register_persistent 合并。实际 WASM 迁移曾暴露“新设备空列表覆盖导入收藏”，已用按条目合并修复；删除后导入旧备份不会复活，重新收藏采用更新的时间。兼容早期 ID 列表。录音文件及声音通道标签沿用原作，不合成新声音。

目录从唯一 story.json 生成普通 Ren'Py init 常量；玩家不读取被发行排除的作者 JSON。compile_story 同时生成标准 DSL、图像绑定和收藏目录，compile_tests 同步原生交互与跨进程收藏断言。继续使用官方 Ren'Py 8.5.3，无自制视觉小说执行器。

离线进度仅累计完成长度、SHA-256 校验和缓存写入的文件与字节。安装失败不写完整标记，保留旧版缓存，提供重试；更新等待所有旧窗口关闭。状态消息仅发给本作品 scope。浏览器测试在启动前核对展开目录的全部真实字节，避免破损包停在引擎启动画面后才报超时。
