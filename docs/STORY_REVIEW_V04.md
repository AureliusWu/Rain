# v0.4 场景与路线审阅

沿用用户授权继续制作的雨夜重逢候选，不新增角色、超自然设定或过去的重大秘密。17 个新增叙事场景分别起草，分别保存 `prompts/script/v04/*_v1.md`；JSON 记录请求路径与 SHA-256。旧台词的六个语音 ID、文字和文件保持绑定。Agent 完成编辑审阅；最终创作选择仍由用户试玩决定。

## 剧情事实

- 玩家从序章知道自己写过信。truth_known 只表示许澄明确知道作者，不表示玩家突然获得记忆。
- 她收到的是未拆信封；整个片段没有拆信动作。旧照片是书店借展品，她有自己的保存理由，不等于等候玩家三年。
- 取物目的在开场交代。纸箱先从出口取到长椅旁，信可暂放箱盖；离开前封箱。信封最终留在玩家口袋。
- 两张旧照片分别是歪的定时合照与正的收展照；Normal 发第二张，True 展示第一张。
- 立绘姿势保持站立；小店坐下的尾声使用黑场，不出现站立的人物叠图。
- 合流场景不假设玩家已问过新书店近况，也不把尚未坦白的信描述成女主已读过。
- 同行低状态仍可在出口分别；独自离开绝不被数值带进同伞、小店结局。网约车尚未到站，Normal 的箱子仍可靠着玩家腿。

## 选择与判定

| 选择 | 效果 | 后续独立场景 |
|---|---|---|
| q01_care / q01_business | affection +1、trust +1 / trust -1 | s02_care / s02_business |
| q02_honest / q02_defer | trust +1、truth_known=True / trust -1 | s03_honest / s03_deferred |
| q04_revisit / q04_concrete | affection +1、trust +2、truth_known=True / trust +1 | s04_repair / s04_concrete |
| q03_walk / q03_leave | affection +1 / trust -1 | s05_shared_path / s05_separate_path |

q04 在 q03 之前游玩，保留旧 ID。信任入口：trust ≥ 1 到 s04_open，否则 s04_reserved。四次选择共 16 条完整路线，四条 True、十二条 Normal。只有同行后 affection ≥ 2、trust ≥ 2 且 truth_known 才进入 True；选择分别时直接 Normal。

True 的四条路径：关心/坦白/再说明/同行，关心/坦白/约联系/同行，关心/暂缓/再说明/同行，办事/坦白/再说明/同行。补救只能修复一次早期回避；两次回避不会因一句追加说明就跳过关系建立。

## 机械检查的边界

校验 HH:MM 声明沿路径递增、章节入口、状态边界、所有选择后果、所有结局可达、无空稿和 Prompt 一致；不能自动证明回忆叙述、人物动机或阅读节奏没有问题。上述事实与分支合流由编辑审阅确认。

单路线约 5,050–5,350 字；按 250–350 字/分钟，另计选择与画面停留，预估 17–24 分钟。全分支约 7,000 字，仍未达到最终 15,000–30,000 字与 30–60 分钟目标。未做真人阅读计时。主要地点继续复用站台，增加核心背景与 CG 留待资产阶段。
