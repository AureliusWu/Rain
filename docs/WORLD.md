# 世界与时间线（样片提案）

现代中国的虚构江城。旧车站即将关闭，雨夜的最后一班车已取消。地点和标识均为原创，不对应现实运营车站。

时间线：三年前，主角离城前把未送出的信夹在车站展览留言册中。今晚 21:40，他回来取寄存的书，物品已经由站务搬到出口。许澄来领回当年书店借展的照片，站务也把旧留言册里的信交给了她。两人曾相识，对离别的理解并不相同。

21:43 重提照片；21:47 交还未拆的信；21:52 讨论联系方式；21:56 离开站台。True 尾声在 22:01 的附近小店，Normal 尾声在 22:06 的车站外。照片包含两人，因为主角设置了定时快门。手机当前有电，“手机没电”是过去未联系时的借口。

世界没有已确认的超自然规则。表面的谜题来自未完成的沟通，真相由行动和对话揭开。

样片结束时只解决“是否一起走下站台”的小事件，完整作品真相暂不锁定。
