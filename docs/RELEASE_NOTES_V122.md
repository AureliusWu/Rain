# 雨停之前 v1.2.2

历史记录支持关键词搜索、人物筛选、结果数量和一键清除。筛选后仍能重听原台词；关闭再打开历史面板会重置筛选。修复清除筛选意外结束历史菜单的问题，以及网页版输入框部分按键被引擎拦截的问题。

Windows 独立 ZIP 与官方 Ren'Py WASM PWA 沿用六章、560 台词 ID、16 条状态路线、17 句录音及现有 v1 存档身份。网页版支持完整离线阅读和原生存档 ZIP 导入、导出。

两个下载包均使用同一发布提交已经通过的 CI 原始字节。Windows 要求源码及独立 EXE 各 37 用例 / 477 断言、退出后新进程读档、公开 v1.1.0 真实旧档升级、两遍语音与历史前缀、178 张原生 PNG 及 85 资源审计。PWA 要求 14 项实际浏览器检查、公开站点相同 worker revision、中文输入、存档迁移和断网重开。

下载包身份、原始工件 ID / SHA-256、实际 CI 链接、公开 PWA 修订及用户发布授权写入 `RELEASE_METADATA.json`；`SHA256SUMS.txt` 可校验两个 ZIP 和元数据。发布过程先回读草稿下载，再公开发布并重新下载验证。

用户已要求“完成发布版本更新闭环”。普通电脑 / 中文路径、物理设备安装、DPI、真人试听、阅读计时及创作最终定案继续保留待验。Windows 自动化使用 dummy 音频；自动执行时间不作为真人阅读时长，新版不宣称真人或新增直接逐图审阅通过。原正式版本标签与下载资产保持原样。
