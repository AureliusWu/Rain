# 项目约束

本项目以用户提供的《AI Galgame 项目执行文档 v1.0》为执行依据。

目标是 Windows 离线中文视觉小说，并作为 AI 全栈练习。最终规模为 30–60 分钟、一个主要成年女主、一个玩家角色、15–30 个场景、至少三个关键选择、两个结局，包含存读档、历史、快进、自动播放、设置、音量和全屏。

优先级：可完成 → 可运行 → 剧情体验 → 视觉一致性 → 工程质量 → 功能数量。

技术：Ren'Py 8.5.3、Python、标准 Ren'Py DSL、JSON、Pillow、FFmpeg、GitHub Actions。开发工具与模型不进入玩家运行环境。禁止自研引擎、实时 LLM 剧情和服务器。

## 当前执行范围

1. v0.1.0：工程验证、临时人物、背景、BGM、一个选择、不同回应、中文默认 GUI、存读档、Windows ZIP。
2. v0.2.0：5–10 分钟 Vertical Slice；可审阅的女主、背景、UI、剧情、CG、关键语音与两个片段结局。
3. v0.3.0：用户授权继续下一阶段，沿用现有候选许澄制作七种一致表情，完善 Character Bible、Prompt 组合与实际运行测试。
4. 当前保持 8 场景样片规模；完整 30–60 分钟剧情属于后续章节阶段。继续开发不代表用户已最终批准美术或重大结局。

## 创作决策

样片提案名《雨停之前》：雨夜旧车站重逢；女主许澄，23 岁；清爽日系二维蓝白 UI。用户尚未选择正式主题与视觉，因此这些都是可修改的草案，不代表最终批准。

## 工程决策

剧情 JSON 是唯一事实来源。小型离线编译器输出 Ren'Py label/menu/if；引擎负责运行、回退、保存和界面。三个状态变量：affection、trust、truth_known。遍历全部可达状态路径，不只检查图上的边。

只维护 main。源资产位于 assets_source，发布资产位于 game。文件名、台词 ID、Prompt、版本、来源、许可证和哈希可追踪。Python 校验始终先于引擎构建。

## 完成定义

代码 + 实际运行 + 测试通过 + 文档同步。跨平台构建与 Windows 实机运行分别记录；未执行的检查不记为通过。v1.0 前必须有普通 Windows 电脑双击、两个结局、存读档与音频验收。
