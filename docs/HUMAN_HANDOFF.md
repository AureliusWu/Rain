# 真人后续统一操作清单

依据用户 2026-10-05 指示：“你专心做好你能做的部分，所有需要真人操作的后续我会统一操作。”工程、回归、构建、机器证据和可审阅材料继续推进；下列事项集中保留，用户无需逐批操作。未做的项目保持待验收，机器执行记录不能替代它们。

建议在原生 1080p 与体验打磨完成的同一份最终候选包上统一执行。记录具体 VERSION、commit、ZIP 文件名与 SHA-256，避免把旧包结果沿用到改动后的新包。当前 v0.7 Alpha 的绑定信息见 ALPHA_ACCEPTANCE_V07.md；v0.8 仍在 Windows 验收。

| 真人事项 | 操作与记录 | 状态 |
|---|---|---|

| 关键配音与混音试听 | 逐句听 17 句关键语音；检查错读、缺字、断句、音色及音量；听三首音乐、两种雨声、纸张 / 消息音效、循环与淡入淡出 | 待用户统一操作 |
| 普通 Windows 离线试玩 | 用未注入测试脚本的原始 ZIP 在可写目录完整解压，断网双击 EXE；检查两结局、保存后退出再读取、回退改选、历史、快进、自动播放、独立音量和全屏 / 窗口 | 待用户统一操作 |

| 最终创作定案 | 审阅主题、成年女主许澄、七种表情、四个背景与 CG、音色、重大剧情及两个结局；指出保留或修改项 | 待用户统一操作 |

统一回报格式：包 VERSION / commit / SHA-256；系统与显示 / 声音设备；路线与选择；计时；逐项通过或具体问题；问题所在台词、场景、操作及截图 / 录音；创作保留或修改意见。可分次填，但所有结论需绑定同一候选版本。

工程侧负责生成实际候选、哈希、自动回归证据、角色 / 美术 / 声音审阅材料与修复；收到真人结果后再处理具体缺陷，补齐内容冻结及 v1.0 正式发布记录。
