# 雨停之前 v0.3.0 — 角色表情版

许澄新增微笑、开心、难过、生气、惊讶、害羞，与原有平静表情组成七种透明立绘，接入重逢、旧照片、沟通与离站的 20 处台词。

- 固定人物、服装、姿态和构图；源图与版本化 Prompt 可追踪。
- 延续 8 场景、3 次选择、Normal / True 两个片段结局，8 种选择组合均可通关。
- AI 背景、旧信 CG、6 句中文关键语音、原创音乐与雨声、蓝色原生 UI。
- 支持存读档（包含当时表情）、历史、快进、自动播放、音量、全屏/窗口和重新开始。
- 发布门槛含 16 个 Python 用例、数据校验、Ren'Py lint、13 个原生交互用例 / 62 个断言，以及 ZIP 解压后的独立 Windows EXE 同套测试。对应 Actions 保留结果与七种表情截图。

下载 BeforeTheRainStops-0.3.0-win.zip，完整解压后双击 BeforeTheRainStops.exe。无需 Python、Ren'Py、模型或联网。SHA256SUMS.txt 用于核验。

本阶段使用独立存档目录，旧版本存档保留。主题、形象与结局方向仍为可审阅方案。单路线预估 6–9 分钟，尚未真人计时；完整 30–60 分钟剧情在后续阶段制作。下一阶段 v0.4 完善章节、场景图与选择影响。
