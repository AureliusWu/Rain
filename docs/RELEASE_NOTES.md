# 雨停之前 v0.2.0 — Vertical Slice

雨夜的旧车站，两位久未联系的旧友，和一封没有寄出的信。中文、离线、可从头走到片段结局的 Windows 样片。

- 8 个场景、3 次选择、Normal / True 两个结局，8 种选择组合都可通关。
- AI 女主基础立绘、雨夜站台背景、交还旧信 CG，蓝色原生 UI。
- 6 句 AI 中文关键语音，原创 BGM 与雨声；支持独立音量和语音试听。
- 存档、读档、历史、快进、自动播放、全屏/窗口和结局后重新开始。
- 发布前进行 Python、数据校验、Ren'Py lint、Windows 原生交互和独立 EXE 测试；测试证据见对应 Actions。

下载 BeforeTheRainStops-0.2.0-win.zip，完整解压后双击 BeforeTheRainStops.exe。无需安装 Python、Ren'Py、模型或开发环境，无需联网。SHA256SUMS.txt 用于核验文件。

主题、角色与画风为待审阅候选。单路线预估 6–9 分钟，尚未真人计时；这不是完整 30–60 分钟作品。v0.1 工程存档不跨版本加载。下一步先试玩确认方向，再制作一致表情和完整路线。
