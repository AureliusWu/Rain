# 美术规范 v1（样片提案）

1280×720、16:9。人物为成年女性的清爽二维日系原创设计，轮廓清晰；背景采用安静、冷蓝雨夜色调，留出 UI 区域。

人物固定：深蓝黑齐肩短发、灰蓝眼睛、右侧银色雨滴发夹、蓝灰针织开衫、象牙白上衣、深蓝及膝裙。所有表情保持同一个人物比例、姿态、服装和线稿。立绘透明 PNG；角色显示区域约画面右侧 60–75%，不遮主要菜单。

Prompt 按身份 + 服装 + 表情 + 姿态 + 镜头 + 画风组合。基础图固定后，表情优先局部编辑。禁止每次重写人物身份。

源图保存在 assets_source，游戏图保存在 game。确定性处理只负责尺寸、格式、命名、校验和；人物改画使用图像生成工具。每张图记录 Prompt 与生成版本。

v0.1 的几何人物和站台是明确的 Placeholder。v0.2 图像是正式资产候选，最终视觉选择仍由用户决定。

v0.2 使用一个雨夜站台背景、normal 透明立绘和一张交还旧信的 CG。True 小店尾声采用 Ren'Py 原生纯黑背景承载文本，避免重复站台 CG 造成地点冲突；完整版本再决定是否增加小店背景。选择栏放在画面下部，不遮住人物脸。默认菜单保留，仅改中文字体、蓝色图元、标题和 Credits。

## v0.3 表情制作

七种表情统一参考 `assets_source/character/heroine_clean_v2.png`；共享身份、服装、姿态、镜头和画风组件位于 `prompts/character/heroine_expressions_v1.json`，每张精确请求在 `heroine_<expression>_v1.md`。只编辑眼眉、嘴与轻微腮红；保留身体、发型、发夹、衣纹与灯光。透明 PNG 按全画布缩放到底部居中的 540×700，不按各图包围盒单独缩放，避免跳动。

自动门槛：七种齐全、尺寸和透明通道正确、参考图与 Prompt 哈希一致、轮廓 IoU ≥ 0.97、包围盒偏差 ≤ 4 像素、全部被台词使用。当前新表情与 normal 的 IoU 为 0.993–0.998，包围盒最多差 1 像素。身份、表情含义、服装细节仍需看图审阅；最终视觉选择由用户决定。
