# v1.1.0 执行环境断开时的远程复核

本地执行环境在完成时序修正的 118 项测试与作者校验后断开。通过仓库接口提交同一修正，完整 Windows 检查继续使用固定 Ren’Py SDK。

`tools.build.export_review` 在五个原生验证进程通过后独立检查真实报告、163 个原始 PNG、85 个包内资产、ZIP CRC、版本、玩家说明、许可、原始语音证据与精确 v1.0.1 升级身份。结果仍标为 `technical_passed_visual_pending`，CI 完成状态和 artifact 身份另由 API 核对。

52 个关键视图先核对原始 PNG SHA-256。此前确实查看过的图仅在字节哈希完全相同时复用；被拒绝候选的源码前缀观察只证明对应画面，不证明整体成品通过。其他视图生成相同分辨率、quality 95 的 JPEG 复核副本，副本与原 PNG 都记录 SHA-256。AI 必须实际查看这些副本并填写观察结果，不能把解码、尺寸或技术通过冒充逐图查看。

完整 JSON 以编号的 base64 块输出到 GitHub job log；长度、块数和 SHA-256 用于读取时核对。图像副本是查看渠道，原始 PNG 和玩家 ZIP 保持不变。新的逐图记录明确披露 JPEG 复核限制，不称为原始 PNG 的直接查看。

正式发布仍绑定成功 Windows CI、同一原始 ZIP、用户发布授权与真实 pending 的真人清单，publisher 从原 artifact 发布并下载回读。普通电脑 / 中文路径 / DPI、真人试听、阅读计时和创作定案仍由用户统一操作。
