# v0.9 原生 1080p 适配

原生画布 1920×1080，默认窗口 1280×720；Ren'Py 8.5.3 负责缩放和输入。沿用全部剧情 ID、三种状态、四选择、16 路线、17 句录音和两个候选结局。

| 项目 | v0.8 | v0.9 |
|---|---|---|
| 原生画布、背景、CG、全屏覆盖图 | 1280×720 | 1920×1080 |
| 透明立绘 | 540×700 | 810×1050 |
| 正文 / 姓名字体 | 27 / 30 | 40 / 45 |
| 对话框高 / 文本起点 / 宽 | 185 / (268, 50) / 744 | 278 / (402, 75) / 1116 |
| 选择按钮宽 / 中心 | 790 / y=450 | 1185 / y=675 |
| 导航栏宽 / 内容区域宽 | 280 / 920 | 420 / 1380 |
| 存档卡 / 缩略图 | 276×206 / 256×144 | 414×309 / 384×216 |
| UI / 快捷栏字体 | 24 / 14 | 36 / 21 |
| 立绘底部偏移 / 轮廓容差 | 20 / 4 | 30 / 6 |

字体、按钮、滑块、间距、历史、设置、存读档、结局卡和菜单逐项调整。七表情保持同一位置；CG 仍隐藏普通立绘。

AI 源图及精确历史 Prompt 保留，没有重新生成美术。立绘由 1024×1536 RGBA 源图重新缩入 810×1050；四背景与旧信 CG 源图为 1672×941，用 LANCZOS 重采样到 1920×1080，约 1.15 倍放大，细节受原图限制。20 原创蓝色图元直接在目标尺寸重画到 assets_source/ui/v3，其余原 GUI 字节保存在 assets_source/ui/legacy720，按明确 1.5 倍配方导入。图标保留 256×256。

60 图片都有源文件、来源许可、源 / 输出哈希、像素元数据及重建配方。重复迁移不升级未改资产版本；明确圆角像素避免 Pillow 版本差异，编码差异不改已保存的源字节。

```bash
python -m tools.image_process.migrate_1080
python -m tools.image_process.import_asset --check
```

Windows CI 真实设置桌面 1920×1080，失败则停止。实际渲染每句正文，检查最终中文字体下的换行高度。主集合 31 用例 / 359 断言 / 65 截图；跨进程读档另 1/10 / 1 截图。scaled-* PNG 必须物理 1280×720，其余必须 1920×1080；完整解码及错误尺寸反例都实际执行。源码和 ZIP 独立 EXE 使用同一全局集合，不沿用旧包通过结果。

本地 81 项 Python 和全部作者检查通过；本候选 Windows 引擎与包验收待执行。普通电脑 100% / 150% Windows DPI、真实听感、计时与最终创作仍由用户后续统一操作，内容未冻结。
