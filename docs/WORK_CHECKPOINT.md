## 本轮恢复规则

1. 每一批工作都先运行 `python -m tools.preflight`，确认版本、生成脚本和工作现场一致。
2. Ren'Py SDK 下载使用 `.part` 临时文件；校验失败、下载中断或解压失败时保留已有运行库。故障恢复由 `tests/test_sdk_recovery.py` 覆盖。
3. `main` 推送只做验证、构建和 Windows 源码/独立 EXE 验收，不再自动创建 Release。
4. Release 只从手动发布工作流触发，并重新验证所选提交、VERSION、ZIP 与独立 EXE。
5. 剧情按小批次闭环：正文 → 生成脚本 → 快速校验 → checkpoint → 再进入下一批。避免一次积累几十个未同步文件。
6. CI 通过后若尚未完成截图、哈希、Release 或状态记录，必须明确写“测试通过，发布未完成”，不能把阶段标成完成。
7. 真人试听、Normal/True 阅读计时和普通 Windows 电脑试玩继续作为 Human Gate，不由 CI 代替。
